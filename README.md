**VocalBridge AI** is a modern, responsive web application designed to break language barriers in real-time. Built with a sleek Glassmorphism UI, it translates both spoken voice input and typed text across 30+ global languages seamlessly.

---

## ✨ Features

- 🎙️ **Speech-to-Text Recognition:** Native speech input powered by the HTML5 Web Speech API (supports Urdu, Arabic, English, Spanish, etc.).
- 🔊 **Text-to-Speech Audio Playback:** Listen to the translated output in accurate native accents.
- ⚡ **Instant Translation:** Powered by a fast, reliable Google Translation API endpoint with live typing auto-translation.
- 🌐 **30+ Supported Languages:** Seamlessly switch between Urdu, Arabic, English, Hindi, Turkish, French, Japanese, and many more.
- 🎨 **Modern Glassmorphic UI:** Styled with Tailwind CSS, custom dark mode, vibrant gradient glows, and mobile responsiveness.
- 🔄 **Language Swap & One-Click Copy:** Designed for effortless conversation flow.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN), FontAwesome Icons
- **APIs & Web Services:**
  - [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) (Speech Recognition & Speech Synthesis)
  - Google Translate GTX API (Reliable Translation Engine)
- **Deployment:** GitHub Pages
